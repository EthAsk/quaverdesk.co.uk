Set up Grandstream phones with Quaver Desk

Grandstream GRP desk phones set themselves up on Quaver Desk. You add the phone by its MAC address, give it your provisioning address once, and it downloads its account, busy lamp keys and settings, then checks for changes every day.

Which Grandstream phones

The GRP26xx range (such as the GRP2601, GRP2602, GRP2612, GRP2614, GRP2616 and GRP2670) on current firmware. Phones only connect encrypted, so very old firmware may need updating first. Other Grandstream models work as ordinary SIP phones, with their settings typed in by hand.

Three steps

  1. Add the phone. In Quaver Desk go to Admin → Phones and apps → Add a phone. Choose the person, choose Grandstream as the make, and enter the MAC address from the label on the back.
  2. Point the phone at Quaver Desk. Open the phone's web page (its IP address is in the phone's network status menu; a new phone's login is usually admin with the password on its label, or admin). Go to Maintenance → Upgrade and Provisioning and:
    • set Config Upgrade Via to HTTPS;
    • paste the Config Server Path: this is the address without https://, and the Automatic set-up card in Quaver Desk has a copy button for exactly that;
    • enter the HTTP/HTTPS User Name and Password from the same card;
    • press Provision.
  3. Check it worked. The phone signs in a moment later. The phone log in Quaver Desk shows Phone downloaded its settings.

The usual slip

If nothing appears in the phone log, the server path almost always still has https:// on the front. Grandstream adds it for you from the Config Upgrade Via setting.

DHCP option 66

You can set the provisioning address once on the router as DHCP option 66, but some Grandstream firmware ignores the login inside the address. If the phone log says Wrong provisioning login, enter the user name and password on that phone once by hand.

What the phone is given

  • Its account, encrypted: TLS for signalling and compulsory SRTP for audio.
  • The person's name on its screen, UK time with summer time, and *00 on its voicemail key.
  • A new random password for its own web page. The user login gets one too, so neither keeps its default.
  • Busy lamp (BLF) keys for the colleagues you tick: see who is on a call, press to call them, press during a call to transfer.
  • A daily check for changes. Settings changed on the phone itself are put back at its next check.

Kept safe

  • A new phone has 24 hours to fetch its settings. The address it uses becomes its trusted address; a request from anywhere else waits for an admin to press Approve.
  • You can lock a phone to your office's internet address or host name, so it only signs in from there.
  • Every download, refusal and change is in the phone log.

The full walk-through, including DHCP option 66, approvals and troubleshooting, is in desk phone set-up.
