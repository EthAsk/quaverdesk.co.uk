Set up desk phones automatically

Add a Yealink, Grandstream or Fanvil phone in Quaver Desk and point it at your provisioning address once. The phone downloads its account, a new admin password, UK time, voicemail and busy lamp keys by itself, then checks for changes every day.

Before you start

  • You need the Plus or Pro plan, and an admin login.
  • Supported phones: Yealink T-series, Grandstream GRP26xx and Fanvil X series, on current firmware. Other SIP phones and apps work too, but you type their settings in by hand.
  • Phones only connect encrypted (TLS and SRTP), so very old firmware may need updating first.
  • Have the phone's MAC address ready. It's on the label on the back.

1. Add the phone

  1. Go to Admin → Phones and apps → Add a phone.
  2. Choose the person and give the phone a name, such as "Reception desk".
  3. Under Set up automatically, choose the make, and enter the MAC address (any format, for example 80:5E:C0:12:34:56).
  4. Optionally, fill in Only sign in from with the office's public IP address or host name. The phone then only works from the office.
  5. Press Add phone.

For a phone already in the list, choose its make and MAC address on its Automatic set-up line and press Save.

2. Point the phone at Quaver Desk

The Automatic set-up card on the same page shows your company's Server URL, User name and Password, each with a copy button. Open the phone's web page (type its IP address, shown in its network menu, into a browser; a new phone's login is usually admin / admin) and enter them:

MakeWhereThen
YealinkSettings → Auto Provision: Server URL, User Name, PasswordAuto Provision Now
Grandstream (GRP)Maintenance → Upgrade and Provisioning: Config Upgrade Via HTTPS, Config Server Path (the address without https://; the card has a copy button for it), HTTP/HTTPS User Name and PasswordProvision
Fanvil (X series)System → Auto Provision: Server URL, User Name, PasswordApply

After its first download, the phone's web page has its own random admin password. To see it, press Show admin password on the phone's line.

3. Or use DHCP option 66

Instead of typing the address into every phone, you can set it once on the office router as DHCP option 66, as a text value. The card shows the value to use, with the login built in: https://phones:password@your-address/provision/…/.

  • Add each phone first (step 1). Option 66 only tells phones where to look. A phone that hasn't been added is refused, and the refusal shows in the phone log.
  • Factory-reset second-hand phones. They may have option 66 turned off or another server saved.
  • Yealink takes the login from the address. Some Grandstream and Fanvil firmware ignores it. If the log says Wrong provisioning login, enter the user name and password on that phone once by hand.

Keep the password private. Anything on the network can read option 66, so it can read the password too. With the password and a phone's MAC address, someone could download that phone's SIP password. Either use option 66 only on a separate network for phones (a voice VLAN), or use it just for the rollout, then remove it and press Make a new address and password.

4. Check it worked

Look at the phone log at the bottom of Phones and apps. You should see Phone downloaded its settings, and the phone should sign in a moment later. The phone's line shows when it last fetched its settings, from where, and its model and firmware.

The phone gets:

  • its account, encrypted: TLS on port 5061, and compulsory SRTP for audio;
  • the person's name on its screen;
  • a new random password for its web page;
  • UK time, with summer time;
  • *00 on its voicemail key;
  • its busy lamp keys, if you've chosen any;
  • a daily check for changes.

Settings changed on the phone itself are put back at its next check.

Busy lamp keys (BLF)

A busy lamp key shows what a colleague's phone is doing:

LampMeans
Off or greenFree
FlashingTheir phone is ringing
On or redThey're on a call

Colours vary a little by make. Press the key to call the colleague. Press it during a call to transfer the call to them.

To add them:

  1. On Phones and apps, open Busy lamp keys on the phone's line.
  2. Tick the colleagues you want.
  3. Press Save keys.

Key 1 stays the phone's own line. Colleagues follow on keys 2 onwards in extension order, up to 20. A phone set up automatically gets them within a minute.

  • Until you save keys for a phone, Quaver Desk leaves its keys alone. Once you have, unticked colleagues' keys are cleared.
  • People who leave, or who are made forward-only, drop off the keys automatically.
  • Phones set up by hand: the same panel lists a value for each colleague. On the phone's web page, set a key's type to BLF, account 1, and enter that value.

Each person's lamp has its own private address, which is only given to phones in the same company. A ringing lamp calls the colleague; it doesn't pick up their call.

The phone log

Quaver Desk keeps a record of what happens to your phones, showing when, which phone, who did it (or The phone), from which IP address, and details:

  • every settings download and every refusal;
  • every time someone shows or changes a phone's password;
  • every change to a phone's set-up, sign-in lock or busy lamp keys;
  • every phone added or removed.

Admins see the last 100 on Phones and apps. If we host your phone system, our support team can see them too.

Troubleshooting

What you seeWhat to check
Nothing in the phone logThe phone didn't reach Quaver Desk. Check the address was copied exactly, the phone can reach the internet over HTTPS, and its firmware is current. On Grandstream, check the server path has no https://.
Wrong provisioning loginRe-enter the user name and password. With DHCP option 66, enter them on the phone by hand.
No phone is set up with MAC address …Add the phone, or correct its MAC address.
Asked from outside the addresses the phone is locked toThe office's public IP address isn't in the phone's Only sign in from list.
Downloads its settings but won't sign inThe firewall must let the phone reach the phone system on port 5061, and the phone must be at an address it's locked to.
Busy lamp keys stay darkPress Send settings now, wait a minute, and restart the phone if needed.
